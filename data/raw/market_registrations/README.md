## 1. Directory Structure

```text
data/raw/market_registrations/
├── README.md                           <- This file (ingestion instructions & schema)
├── vahan/                              <- Raw, unmodified source extracts from Vahan 4.0
│   └── (place yearly/monthly Vahan portal exports here)
└── normalized/                         <- Standardized, schema-aligned extracts
    └── (generated by src/market_data_ingestion.py)
```

---

## 2. Ingestion Rules & Non-Negotiable Safeguards

1. **Original Files Preserved**: Source files placed in `vahan/` must remain byte-identical to the source export. Never alter, smooth, or interpolate data in raw files.
2. **Provenance Traceability**: Every ingested file must have an accompanying entry in `docs/DATA_SOURCE_REGISTER.md` detailing:
   - Source URL / Document reference
   - Access date
   - Vehicle category & fuel type filters used
   - Exact query parameters
   - Extractor name / verification hash
3. **No Synthetic Fill**: Missing months, missing states, or missing makers must NOT be interpolated or filled with averages. Missing values remain `NULL` or missing records.
4. **Automated Normalization**: Run `python src/market_data_ingestion.py` to validate, standardize, and load data into `data/raw/market_registrations/normalized/`.

---

## 3. Required Schema for Ingested Data

When raw files are normalized, the standard schema produced is:

| Column Name | Data Type | Description | Allowed Values / Constraints |
|---|---|---|---|
| `year` | INTEGER | Calendar year or Fiscal year of registration | e.g., 2014–2025 |
| `month` | INTEGER | Calendar month (1–12), optional if annual | 1 to 12, or NULL for annual |
| `state_name` | VARCHAR | Standardized state or UT name | Aligned with standard 36 States/UTs |
| `state_code` | VARCHAR(2) | Two-letter state code | e.g., 'MH', 'KA', 'DL', 'TN' |
| `vehicle_category` | VARCHAR | Standard vehicle category | '2-Wheeler (e2W)' |
| `fuel_type` | VARCHAR | Fuel type specification | 'ELECTRIC' |
| `manufacturer` | VARCHAR | Standardized OEM name | Mapped via OEM dictionary |
| `registrations` | INTEGER | Count of registered vehicles | Non-negative integer (>= 0) |
| `source` | VARCHAR | Primary source identifier | e.g., 'MoRTH Vahan 4.0 Dashboard' |
| `source_url` | VARCHAR | Exact source retrieval URL | Official portal URL |
| `source_access_date` | DATE | Date of extraction | ISO-8601 (YYYY-MM-DD) |
| `provenance_status` | VARCHAR | Provenance classification | 'verified_primary_source' |
