# Power Query (M) Data Preparation Specification

## 1. Overview & ETL Architecture

This document specifies the data transformation, cleansing, and schema shaping procedures implemented in **Power Query (M)** for the Power BI analytical model.

The ETL pipeline connects directly to the verified analytical CSV outputs generated by the DuckDB SQL pipeline under `data/processed/sql/`. The pipeline enforces:
1. **Strong Typing**: Eliminates implicit type guessing, applying explicit data types (`Currency.Type`, `Int64.Type`, `type number`, `type text`, `type date`).
2. **Text Standardization**: Standardizes model names, vehicle classifications, and trims whitespace.
3. **Null Handling**: Normalizes empty strings `""` to explicit `null` values so numerical DAX aggregations (`AVERAGE`, `MEDIAN`, `COUNTROWS`) behave predictably.
4. **Provenance Preservation**: Retains audit tags (`verification_status`, `Data_Ingestion_Date`, `Is_Verified_Catalog`) across all model entities.
5. **Fail-Closed Market Isolation**: Defines an empty table schema for `PendingMarketRegistrations` (0 rows) to ensure unverified proxy registration data is never loaded.

## 3. Step-by-Step Table Transformations

### 3.1 `DimManufacturer` (Manufacturer Dimension)
- **Source File**: `sql_competitive_analysis.csv`
- **Transformation Steps**:
  1. Load CSV via `Csv.Document(File.Contents(DataFolderPath & "sql_competitive_analysis.csv"))`.
  2. Promote the first row as column headers (`Table.PromoteHeaders`).
  3. Select relevant columns: `manufacturer`, `mfg_product_count`, `mfg_portfolio_share_pct`, `verification_status`.
  4. De-duplicate across `manufacturer` using `Table.Distinct` to establish a unique primary key.
  5. Apply explicit data types: `mfg_product_count` -> `Int64.Type`, `mfg_portfolio_share_pct` -> `type number`.
  6. Append audit column `Data_Ingestion_Date` with the current ingestion date.

### 3.2 `DimProduct` (Product Catalog Dimension)
- **Source File**: `sql_competitive_analysis.csv`
- **Transformation Steps**:
  1. Load CSV and promote headers.
  2. Select `product`, `manufacturer`, `category`, `verification_status`.
  3. Deduplicate across `product` to enforce a unique primary key.
  4. Apply `Text.Trim` to clean trailing or leading whitespace across strings.
  5. Add boolean audit flag `Is_Verified_Catalog` (`true` when `verification_status = "verified"`).

### 3.3 `FactProductMetrics` (Core Metrics Fact Table)
- **Source File**: `sql_competitive_analysis.csv`
- **Transformation Steps**:
  1. Load CSV and promote headers.
  2. Select metric columns: `product`, `manufacturer`, `price`, `battery_kwh`, `certified_range_km`, `top_speed_kmph`, `motor_power_kw`, `price_per_km`, `price_per_kwh`, `verification_status`.
  3. Replace empty string values `""` with `null` across all numerical columns using `Table.ReplaceValue`.
  4. Cast `price`, `price_per_km`, and `price_per_kwh` to `Currency.Type`.
  5. Cast technical specs (`battery_kwh`, `certified_range_km`, `top_speed_kmph`, `motor_power_kw`) to `type number`.
  6. Add calculated column `energy_efficiency_wh_per_km` using defensive formula:
     ```powerquery
     if [battery_kwh] <> null and [certified_range_km] <> null and [certified_range_km] > 0 
     then Number.Round(([battery_kwh] * 1000.0) / [certified_range_km], 2) 
     else null
     ```

### 3.4 `CompetitiveAnalysis` (Competitive Rankings Mart)
- **Source File**: `sql_competitive_analysis.csv`
- **Transformation Steps**:
  1. Load CSV and promote headers.
  2. Select `product`, `manufacturer`, `manufacturer_rank`, `product_rank`, `price_efficiency_rank`, `range_rank`, `speed_rank`, `mfg_portfolio_share_pct`.
  3. Replace empty strings with `null`.
  4. Cast all ranking fields to `Int64.Type`.

### 3.5 `PricingAnalysis` (Pricing Mart)
- **Source File**: `sql_pricing_analysis.csv`
- **Transformation Steps**:
  1. Load CSV and promote headers.
  2. Select `product`, `manufacturer`, `price`, `price_percentile`, `price_quartile`, `product_price_rank`, `avg_market_price`, `mfg_avg_price`, `relative_price_position`, `price_premium_vs_market_pct`.
  3. Replace empty strings with `null`.
  4. Cast `price_quartile` and `product_price_rank` to `Int64.Type`.
  5. Cast `price`, `avg_market_price`, and `mfg_avg_price` to `Currency.Type`.
  6. Cast `price_percentile` and `price_premium_vs_market_pct` to `type number`.

### 3.6 `ProductPositioning` (Positioning Mart)
- **Source File**: `sql_product_positioning.csv`
- **Transformation Steps**:
  1. Load CSV and promote headers.
  2. Rename `model_name` to `product` to maintain uniform primary key naming across the model.
  3. Select segmentation buckets (`price_bucket`, `range_bucket`, `battery_bucket`, `performance_bucket`, `positioning_summary`).
  4. Cast integer counter metrics (`manufacturer_budget_count`, `manufacturer_midmarket_count`, `manufacturer_premium_count`) to `Int64.Type`.

### 3.7 `KPIStatus` (KPI Audit Register)
- **Source File**: `sql_kpi_results.csv`
- **Transformation Steps**:
  1. Load CSV and promote headers.
  2. Cast `value` to `type number`, `calculation_date` to `type date`, and remaining columns to `type text`.

### 3.8 `PendingMarketRegistrations` (Fail-Closed Registration Table)
- **Source**: Empty M table constructor `#table(...)`.
- **Implementation**:
  ```powerquery
  let
      EmptySchema = #table(
          type table [
              Date = date,
              Month = Int64.Type,
              Year = Int64.Type,
              State = text,
              VehicleCategory = text,
              FuelType = text,
              Manufacturer = text,
              Registrations = Int64.Type,
              Source = text,
              VerificationStatus = text
          ],
          {} // Zero rows: strictly fail-closed
      )
  in
      EmptySchema
  ```

## 4. How to Load Scripts into Power BI Desktop

When creating the report in Power BI Desktop:
1. Open **Power BI Desktop**.
2. Click **Transform Data** to open the **Power Query Editor**.
3. Under **Home**, click **Manage Parameters** > **New Parameter**:
   - Name: `DataFolderPath`
   - Type: `Text`
   - Current Value: Enter the path to `data/processed/sql/`.
4. For each table, click **New Source** > **Blank Query**.
5. Click **Advanced Editor** and paste the corresponding M query from [`powerbi/power_query_m_scripts.m`](file:///c:/Users/Tanya%20Verma/OneDrive/Desktop/Market-Business-Strategy-Intelligence/powerbi/power_query_m_scripts.m).
6. Click **Close & Apply**.
