# Strategic Analysis

## Scope

This section documents the reusable strategic scoring framework that combines market attractiveness, competitive intensity, product-market fit, and geographic attractiveness into a single 0-100 score.

## Status

The template exists in [data/processed/strategic_priority_template.csv](data/processed/strategic_priority_template.csv), but it is intentionally left pending until all required inputs are verified.

## Methodology

The score is defined as a weighted sum:

market attractiveness * 0.35 + competitive intensity * 0.25 + product-market fit * 0.25 + geographic attractiveness * 0.15

Weights are analytical assumptions documented in the code and are not presented as universal benchmarks.

## Interpretation

The framework is useful for future prioritization once verified market and state inputs are available. It must not be used to create unsupported strategic rankings today.
